# Porovaaka 1.7.9 – Windows-asennus

**[Lataa koko asennuspaketti (ZIP)](https://github.com/paliskuntainyhdistys/porovaaka-179/releases/download/v1.7.9-20260925/Porovaaka-1.7.9-Windows-x64.zip)**

Windows 10/11, Intel/AMD x64. Paketti sisältää asennusohjelman, aloitusasetukset,
suomenkieliset ohjeet, FTDI-ajurit sekä tarkistussummat.

1. Lataa ZIP ja valitse Windowsissa **Pura kaikki**.
2. Sulje Porovaaka ja avaa puretusta kansiosta `Porovaaka-Setup-1.7.9.exe`.
   Asenna normaalina käyttäjänä sillä Windows-tilillä, jolla punnitukset tehdään.
3. Ensiasennuksessa avaa **Tuo käyttöönottoasetukset…** ja valitse
   `Porovaaka-aloitus.porovaaka-setup.json` ennen ensimmäisen erän luomista.
4. Valitse teurastamo, vaakalaite ja COM-portti sekä syötä todelliset hinnat.
   Tarkemmat käyttöönotto- ja vaakakoeohjeet ovat paketin tiedostossa
   `client-installation-fi.md`.

Päivityksessä ota ensin varmuuskopio. Suorita asennus samalla Windows-tilillä;
aloitusasetuksia ei tuoda uudelleen.
